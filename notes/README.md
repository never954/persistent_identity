# notes/ — internal, not part of the paper

Development notes and course material, kept in one folder so it can be left out of the
copy of the repository that goes to reviewers (`git archive` it without this folder, or
delete it in the review copy).

| File | What it is |
|---|---|
| `PROJECT_CONTEXT.md` | Decision log and project history, written as we went |
| `PERSISTENT_MEMORY.md`, `LIVING_HOUSE.md` | Development write-ups of the memory system and the living house, including failures found in play. Their numbers are from development runs; the paper's numbers come from `analysis/` |
| `RESULTS_EXPLAINED.md` | Plain-language notes on early Study 1 results |
| `SUBMISSION_PLAN.md` | Venue choice, reviewer risks, checklist |
| `VIVA_GUIDE.md`, `TECHNICAL_DOCUMENTATION.md`, `DECK_PROMPT.md`, `shots/` | Computer Graphics & Game Design course deliverables (viva, technical write-up, deck screenshots) |
