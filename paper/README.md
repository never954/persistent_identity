# paper/ — the research paper (IEEE conference format)

`ravenswood.tex` is a **preliminary draft** in IEEE conference format
(`IEEEtran`, two-column). It reports Study 1 (memory level) in full and Study 2
(LLM level) as a preliminary proof-of-concept, with every number generated by the
code in `../research/`.

## Compile it

**Easiest — Overleaf (no install):**
1. Go to overleaf.com → *New Project* → *Upload Project*.
2. Zip this `paper/` folder (the `.tex` plus the `figures/` folder) and upload the
   zip, **or** create a blank project and upload `ravenswood.tex` and the
   `figures/` folder into it.
3. Set the compiler to **pdfLaTeX** (Menu → Compiler) and press *Recompile*.
   `IEEEtran` is built into Overleaf, so nothing else is needed.

**Locally (if you install a TeX distribution — MacTeX/TeX Live):**
```bash
cd paper
pdflatex ravenswood && pdflatex ravenswood   # twice, to resolve references
```
(Run twice so figure/table numbers and citations settle.)

## What's inside
- `ravenswood.tex` — the paper. Title, authors (add your co-author/advisor),
  abstract, intro, related work + benchmarking matrix, the memory-layer model,
  Study 1 (1a–1d with figures and tables), Study 2 (LLM, preliminary), discussion,
  limitations/future work, conclusion, references.
- `figures/` — the five Study 1 figures, copied from
  `../research/results/study1/`. Regenerate them with
  `cd ../research && .venv/bin/python experiments/run_study1.py`, then re-copy.

- Study 1 (memory level) is the solid, calibrated result.
- Study 2 (LLM level) is labelled preliminary; its limitations (small-model source
